04 / ENGINEERING DETAILS

What happens when the happy path isn't enough?

The project includes guards for invalid credentials, missing parameters, unsupported HTTP methods, empty cart/payment states, session invalidation and intermittent browser navigation issues.

CI failures can be investigated with Playwright traces and video artifacts, while k6 uses thresholds as a lightweight performance budget rather than pretending to be a full-scale load test.
