# Aktualizacja portfolio

1. Wejdź do GitHub: `Pattrick97/portfolioQESite`.
2. Podmień `index.html` i `styles.css`.
3. Dodaj do katalogu głównego `CV Patryk Grund.pdf`.
4. Commituj zmiany do `main`.
5. Cloudflare powinien automatycznie wdrożyć nową wersję.
6. Otwórz stronę i kliknij `View CV` oraz `LinkedIn`.

Uwaga: plik CV zawiera spacje w nazwie; link w HTML jest już poprawnie zakodowany.
